# Localgov Finders DB

This module provides a default SearchAPI server using the database backend.

On installation, all finder search indexes which do not have a server set will
be updated with the default server from this module.

Enabling a finder type with this module enabled will set the default server on
the newly-created search index.

You can edit any of the finder search indexes and change the server it uses.

## Requirements

- LocalGov Finders
- SearchAPI DB
